# sdev

sdevは、仕様を文書として整理し、AIエージェントと開発を進めるための小さなツールです。
Product・Requirements・Designのガイドラインとテンプレートを提供し、対話・調査・執筆・実装の進行は利用するエージェントが担当します。

[文書と作業の入口](docs/README.md)から、作業に応じたガイドラインと手順を参照してください。
sdev自身の開発目的は[Product](docs/products/sdev/product.md)、最初の機能は[ガイドライン参照のRequirements](docs/products/sdev/features/guideline-reference/requirements.md)に記述しています。

## 使い始める

このリポジトリをローカルで読み、利用するプロジェクトのAGENTS.mdに次の指示を追加します。
山括弧内を、実際に読める入口のパスへ置き換えてください。

```text
仕様の作成・変更・実装を始める前に、<sdevの配置先>/docs/README.mdを読み、作業に対応するガイドライン・テンプレート・手順に従ってください。
```

テンプレートを利用するプロジェクトへコピーし、そのプロジェクトのProductから書き始めます。
このリポジトリ自身を開発するときは、配置済みの[AGENTS.md](AGENTS.md)が入口になります。
Markdownの参照に、CLIのインストールやビルドは必要ありません。

## 提供しているもの

ガイドライン、3種類のテンプレート、エージェント向けの作業手順と、それらを使って書いたsdev自身の仕様を配置しています。
この開発基盤の確認結果と残る判断は[確認記録](docs/reviews/bootstrap.md)にまとめています。

WebのURLだけで参照する利用方法は目標ですが、公開先と公開URLは決めていません。
公開して内容を確認した入口URLが用意できたら、利用側の参照指示をURLに置き換えます。
CLI、文書のlint、対応関係の可視化、既存文書の移行機能は実装していません。
