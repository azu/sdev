sdev review [--base REF] [--head REF] [--spec PATH] [--prepare] [--input FILE] [--output FILE | --serve [--port PORT]] [--jev [--jev-model MODEL] [--cache-dir PATH]] [--lang en|ja]

RequirementsとDesignを読み、関連する一節と、仕様への対応を確認すべきコード変更を調べます。
  sdev review --base main --serve --jev
  sdev review --base main --output /tmp/review.html
  sdev help review

Jevモードには--serveと、サーバー環境変数のJEV_API_KEYが必要です。
--jevを明示した場合だけ、取り込んだ仕様・コードの情報をhttps://api.typesafe.aiへ送ります。
キーはサーバー側だけで保持し、HTML・ブラウザーのリクエスト・書き出し・キャッシュに含めません。
--jev-modelの既定値は固定モデルjev-1.13.0、--cache-dirは$XDG_CACHE_HOME/sdev/reviewまたは$HOME/.cache/sdev/reviewです。
実際の本文・差分・候補・モデル・判定条件からキャッシュを識別します。破損した結果は取り直し、aliasは1時間で失効します。

クリックで本文へフォーカスし、関連するReq/Designを開いたままにします。ホバーやTabのフォーカス移動では詳細を変更しません。
J/Kで文を移動し、Enterまたはほかの文字入力で直下にコメントを始めます。最初の文字も保持します。
本文内表示とポップオーバーを切り替えられます。「メモをコピー」で対象・比較・コメントをMarkdownとしてコピーできます。
サーバーの「Agentに渡す」は、起動元の実行出力へreview.feedbackのJSON行を返します。Agentは実行中のコマンド出力から読みます。待機中のAgentを自動再開しません。
コメントはページ内で保持するため、閉じる前にコピー・受け渡し・ファイル保存をしてください。下書きは先にコメントとして追加します。
コードの照合では、仕様に残すべき変更か、渡した仕様にその内容があるかを判定します。
結果は確認候補であり、違反の証明ではありません。検査済み数・全体・一部の入力・取得不能を分けて表示します。
Jevは判定を返し、理由文は生成しません。手書きのレビュー項目は動的な照会には不要です。

Gitルートで取り込みます。既定はHEADと作業ツリー（ステージ済み・未ステージ・無視対象でない未追跡）の比較です。
--headは2コミットを比較し、--specはrequirements[.LANG].mdやdesign[.LANG].mdを追加します（複数指定可能）。
同じ機能の文書は読む材料であり、意味的な接続を推測しません。日本語表示は--lang jaを使います。
--prepareは任意の固定JSONを出し、--inputはGitなしでその入力を読みます。補助項目の形式はsdev help reviewを参照してください。
作業ツリーの配信では、保存した仕様とコードをページの再読み込みなしで自動更新します。コメントの元の対象を保持し、判定は変更後の入力を使います。
--input・--head・単一HTMLは固定した比較です。説明に合わせて取り込み済みの本文を書き換えません。
単一HTMLはオフラインで読めますが、Jevへの動的な照会はできません。実装ファイル全文は埋め込みません。

出力の既定値は準備なら標準出力、表示ならsdev-review.htmlです。--output -は標準出力へ出し、既存ファイルは保持します。
--inputは取得用の引数・--prepareと併用できず、--serveは--prepare・--outputと併用できません。
--portには--serveが必要です。省略時は0で空きポートを選び、127.0.0.1のURLを表示してCtrl-Cまで動きます。
本文上限: 片側1 MiB、合計16 MiB、500ファイル。表示できない内容には理由を示します。
終了コード: 成功0 / 取得・入力・出力・サーバーの失敗1 / 引数・設定の不正2。
